About This Project

AI Health Risk Predictor — Machine Learning Based Health Risk Assessment System

Project Objective

This project estimates a user's statistical risk of Diabetes and Heart Disease using machine learning models trained on publicly available clinical datasets. It demonstrates a complete, end-to-end data science and machine learning workflow — from raw data cleaning through model training, evaluation, and deployment as a usable web application.

Technologies Used
  • Python 3
  • Flask (web framework)
  • Pandas & NumPy (data processing)
  • Scikit-learn (machine learning)
  • Matplotlib, Seaborn, Plotly (visualization)
  • Bootstrap 5 (frontend UI)
  • Jupyter Notebook (data science workflow)
  • Joblib (model persistence)
Machine Learning Algorithms Compared

Five classification algorithms were trained and compared for each disease, with the best model automatically selected based on ROC-AUC:

  • Logistic Regression
  • Decision Tree
  • Random Forest
  • Support Vector Machine (SVM)
  • Gradient Boosting
Datasets
  • Diabetes: Pima Indians Diabetes Database (Kaggle) — 768 records, 8 clinical features.
  • Heart Disease: Heart Disease Dataset (Kaggle, based on the UCI Cleveland Heart Disease dataset) — 302 unique records after deduplication, 13 clinical features.
Limitations
  • This is a statistical risk estimate, not a medical diagnosis.
  • Trained on relatively small public datasets, which limits generalizability.
  • The Diabetes dataset was originally collected from an adult female population.
  • The Heart Disease assessment requires clinical test values (ECG, fluoroscopy) that a layperson may not have without recent medical testing.
  • Feature importance reflects overall model behavior, not a per-user causal explanation.
Medical Disclaimer: This system is an educational project and is not intended for medical diagnosis or treatment decisions. Always consult a qualified healthcare professional for any health-related concerns.
